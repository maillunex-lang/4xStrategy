# Дорожная карта v0.1
Все этапы — PROPOSED. Это последовательность результатов, а не обещание сроков. Календарь появится после состава команды, бюджета и первых измерений скорости. Единица планирования — задача с проверяемым результатом.

| Этап | Результат | Условие выхода |
|---|---|---|
| P00 Концепция | Выбранные правила мира и оригинальное направление | Подтверждены Q01/Q02/Q10 и границы первого среза |
| P01 Технические пробы | Выбран стек, контракты, бюджет VPS | Android-проба, решение стека, тестовый стенд |
| P02 Основа онлайн | Вход, база, экономика, очередь, сохранение | Два клиента; рестарт и повтор команд безопасны |
| P03 Вертикальный срез | Карта, марш, PvE, понятный мобильный цикл | Два игрока проходят цикл в одном мире |
| P04 Закрытый MVP | Глубина экономики, PvP, альянсы, обучение | Многодневная игра с восстановлением проигравшего |
| P05 Бета на VPS | Нагрузка, восстановление, баланс, поддержка | Доказана ёмкость, восстановление и готовность беты |
| P06 Выпуск | Подписанная сборка, материалы и выпуск | Пройден выпускной чек-лист и наблюдение после запуска |

Критическая последовательность: P00-01 → P01-01 → P01-02 → P02-01 → P02-02 → P02-03 → P03-01 → P03-02 → P03-03 → P04-01 → P04-02 → P04-04 → P05-01 → P05-02 → P06-01. Остальные зависимости — в [списке задач](tasks.md).

Можно независимо готовить сеттинг, UX и исследование инфраструктуры после определения их входов. Не путать такую независимость с разрешением на несогласованные изменения общего контракта.

После каждого этапа: показать сборку/артефакт, сверить гипотезы, обновить приоритеты и оценку оставшегося. После P03 решить, стоит ли расширять контент и оплачивать постоянную эксплуатацию. Герои, торговля, события и монетизация требуют отдельных карточек после решения об их включении.
