# P01-03: Подготовить тестовый стенд VPS

Зависимости: P01-01

## Результат
Изолированный стенд, воспроизводимый запуск, журнал параметров.

## Работа
Инвентаризировать VPS; настроить тестовое окружение, TLS, секреты и базовую телеметрию.

## Критерии готовности
Стенд проверяется health-запросом; БД закрыта; лимиты и процедура остановки записаны.

## Границы и блокировки
Нужны параметры и доступ к VPS; существующие сервисы не менять без необходимости.

## Передача
После выполнения указать файлы, команды/сценарии проверки, результат и ограничения. Обновить статус здесь и в реестре задач. Для документационных решений приложить подтверждение; для кода — наблюдаемые результаты проверок.
