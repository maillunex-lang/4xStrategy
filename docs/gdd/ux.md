# Android UX — PROPOSED
Основные экраны: поселение, мировая карта, очередь/экономика, отряды, исследования, отчёты, альянс, настройки/учётная запись. Портретная или альбомная ориентация OPEN; сначала проверить кликабельный прототип на телефоне.

## Сценарии
- Вход: восстановить сессию → загрузить разрешённый снимок → показать события за время отсутствия.
- Постройка: выбрать объект → увидеть цену, требования, длительность и результат → подтвердить → получить серверный статус.
- Экспедиция: выбрать цель → состав → время и риски → отправить → отчёт о прибытии.
- Возврат сети: показать устаревшие данные → синхронизировать → подтвердить актуальное состояние. Тайм-аут команды не означает её отмену.

Кнопки касания ориентировочно от 48 dp, текст масштабируется. Не кодировать тип ресурса только цветом. Недоступное действие объясняет причину. Показывать дефицит и цепочку, которая его создаёт. На карте фильтры и масштабы вместо перегруза значками.

Клиент может анимировать и предварительно показывать действие, но трату/результат подтверждает сервер. Фоновая симуляция на телефоне не нужна. Пуши необязательны для прогресса и запрашиваются отдельно после понятного примера пользы.

Обучение MVP: произвести ресурс → построить → исследовать → разведать → отправить отряд → прочитать отчёт. Проверять без объяснений разработчика.
