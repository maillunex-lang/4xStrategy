# 4xStrategy
Рабочее обозначение онлайн-4X для Android. Название и сеттинг не выбраны.

**Стадия:** GDD v0.1, проектирование. Игрового кода и развёрнутого сервера пока нет.

Подтверждено владельцем: Android, онлайн, свой VPS, масштабная стратегия, длинные партии, глубокая экономика. Референс — Last Asylum (`com.phs.global`). Все остальные решения — предложения до явного принятия.
