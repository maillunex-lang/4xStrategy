# Объём продукта — PROPOSED
Целевой продукт масштабный; первый проверяемый выпуск ограничиваем глубиной внедрения, а не обещанием всего контента сразу.

| Срез | Включено | Не включено |
|---|---|---|
| Технический прототип | Два клиента, одна база на игрока, производство, очередь, сохранение | Коммерческий запуск |
| Вертикальный срез | Малый общий мир, разведка, марш, PvE, одна цепочка развития, восстановление подключения | Полная экономика и альянсовые войны |
| Закрытый MVP | Несколько производственных цепочек, исследования, ограниченный PvP, базовый альянс, обучение | Межсерверные войны, магазин, аукцион, сложные осады |
| Бета | Баланс длинного развития, защита новичков, администрирование, восстановление, нагрузочные проверки | Неограниченный онлайн |
| После проверки | Герои, расширенные альянсы, сезоны, дополнительные биомы и события | По отдельным решениям |

Герои в референсе есть; необходимость героев в нашем MVP OPEN. PvP нельзя включать до правил защиты и потерь. Чат и пользовательские тексты требуют отдельного объёма модерации. Магазин и ускорители не внедрять до решения по монетизации.

Ориентир контента MVP: 1 тип поселения, 6–8 зданий, 4–6 ресурсов, 2–3 цепочки, 3 роли войск, 1 дерево исследований. Эти количества — гипотезы для оценки, не утверждённое ТЗ.
