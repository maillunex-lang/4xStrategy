# P00-02: Выбрать оригинальное направление
Статус: BACKLOG  
Этап: P00  
Зависимости: P00-01

## Читать
- [gdd/reference.md](../../gdd/reference.md)
- [gdd/vision.md](../../gdd/vision.md)

## Результат
Три краткие концепции и выбранное направление.

## Работа
Сравнить сеттинг, конфликт, фантазию игрока, визуальную стоимость; предложить рабочие названия.

## Критерии готовности
Есть выбор владельца либо явно сохранён OPEN; при OPEN задача не DONE.

## Границы и блокировки
Не заказывать финальный арт и не копировать референс.

## Передача
После выполнения указать файлы, команды/сценарии проверки, результат и ограничения. Обновить статус здесь и в реестре задач. Для документационных решений приложить подтверждение; для кода — наблюдаемые результаты проверок.
